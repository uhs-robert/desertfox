Get started with Fennec

Fennec is a small build tool for static sites. It reads a folder of Markdown files, applies a template and writes plain HTML. There is no server to run and no runtime to ship.

Install

Download the latest release and put the binary on your path. Then run fennec init in an empty folder to create a site with one page and one template.

Usage

Run fennec build to write the site to the out folder. Run fennec watch to rebuild on every save. Both commands print the pages they wrote and how long each took.

A page is a Markdown file with a short header. The header sets the title, the date and the template. Every other field is free for your own templates to read.

Configuration

Settings live in fennec.toml at the root of the site. The plugin list and the output folder are the two settings most sites change. The install notes list the rest.

Plugins

A plugin is an executable that reads a page on standard input and writes a page on standard output. Fennec runs the plugins in the order the config lists them.

Changelog

Version 2.4 adds incremental builds. Version 2.3 adds the watch command. Version 2.2 moves the config to TOML. Read the usage notes before you upgrade across a major version.
