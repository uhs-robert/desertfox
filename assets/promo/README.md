# Promo images

Two images made from the keycap mark. Both are rebuilt by `tools/render_promo.sh`, so edit the script, not the PNGs.

- `social-preview.png` (1280x640): the GitHub social preview.
- `amo-promo.png` (1400x560): the promo image for the addons.mozilla.org listing.

The owner uploads both by hand: GitHub under Settings > Social preview, and the add-on listing on addons.mozilla.org.
