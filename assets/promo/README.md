# Promo images

Two images made from the keycap mark. Both are rebuilt by `tools/render_promo.sh`, so edit the script, not the PNGs.

- `social-preview.png` (1280x640): the GitHub social preview.
- `amo-listing.png` (1280x800, 1.6:1): the listing image for addons.mozilla.org, the size the site shows.

The maintainer uploads both by hand: GitHub under Settings > Social preview, and the add-on listing on addons.mozilla.org.
