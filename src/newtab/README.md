# newtab

The new tab page. The manifest sets `chrome_url_overrides.newtab` to `newtab.html`, so the page owns every new tab.

- `main.ts`: reads the `new_tab_page` setting through `resolve_new_tab_page` (`shared/config.ts`). A web URL redirects with `location.replace`, so the content script runs on that site as on any page. Anything else draws the built-in page, and so does `newtab.html?builtin`, which `home_page = "desertfox"` opens.
- `render.ts`: draws the built-in page: the clock, the date and the lists, each on unless its setting is `false`. `main.ts` draws through `follow_settings` (`shared/storage_watch.ts`), so a settings change redraws the page: the new page is built off screen and swaps in, the old clock stops first (`run_ticker` returns its stop), and only the first draw may redirect for `new_tab_page`. `newtab_clock` is analog for `true` or `"analog"` and digital for `"digital"`. A 1 second tick moves the hands and rewrites the date, so a tab left open past midnight shows the new day.
- `lists.ts`: the rows under the clock: `[[newtab_links]]` by group, then Recent tabs and Bookmarks, each hidden unless `newtab_recent_tabs` or `newtab_bookmarks` is true (`newtab_*_max` rows, default 8). It runs the tab and bookmark readers of the completion (`background/complete_items.ts`) on the page, with no background message, so it filters on its own: private tabs never show, and a private page lists no tabs. Recent tabs sort by `lastAccessed`, bookmarks by date added. A recent tab row switches to its tab. A reader that fails drops its list. Each row carries its host (without `www.`) and an `icon_url` that is only ever a data: URL from the favicon cache for that host, or none, which draws a letter tile. A tab's own `favIconUrl` is ignored, so the page loads no remote icon.
- `widgets.ts`: the rows of Recently closed (`newtab_closed_tabs`) and Top sites (`newtab_top_sites`), both on by default, `newtab_*_max` rows, 8 each. Closed tabs come from `sessions.getRecentlyClosed` through the completion's `closed_tab_rows`, and a click restores the session. Top sites come from `history.search` over pages visited in the last 90 days: the lifetime visit counts of those pages add up per host, and the host's most visited page is the link. Neither lists anything on a private page. `render.ts` also draws the `newtab_command_hint` button, which runs `cmdline.open` through a `run` message like the colon key. It is a button, not an input, so the address bar keeps its focus.
- `net_widget.ts`: the one fetch-and-cache helper for cards that use the network. `fetch_text` sends no credentials and no referrer, waits 5 s and returns undefined on any failure. `load_cached` keeps one slot per card in `storage.local` (`newtab_net_cache`), shows a stored value of the same key at once, fetches only past the TTL and keeps the stale value when a refresh fails. It checks no setting and no privacy, so each card must do both first. The IP info card reuses it.
- `weather.ts`: the opt-in weather card (`newtab_weather`, default off, Open-Meteo). Nothing is read or fetched while it is off, and a private page does nothing. The place is the browser position when the optional `geolocation` permission is granted, else the geocoded `newtab_weather_city`, else a "Show the weather here" button that requests the permission from its click and sends no request. Coordinates are rounded to 2 decimals. A failure draws nothing. `render.ts` starts it without awaiting, under the date.
- `tile.ts`: one card per row, icon box, title and host, with the whole card as the one anchor, so a hint labels it once. The icon is an `img` (a data: image only) that swaps to the letter tile when it fails to load. The letter tile is a `color-mix` of `--desertfox-primary` and `--desertfox-bg-mantle`, so it follows the theme. The grid in `newtab.html` is two 14rem columns, one on a narrow window, and fills row by row, so DOM order is visual order.
- `icon_cache.ts`: the favicon cache, `favicon_cache` in `storage.local`: entries of host, a 32x32 PNG data: URL and a short key of the tab icon it was redrawn from. At most 200 hosts (the oldest saved drops first) and 6144 characters per icon, so the cache stays under about 1.3 MB. `background/favicon_saver.ts` fills it from the shared `tabs.onUpdated` listener in `background/main.ts`. Firefox gives the background each tab icon as a data: image, and the saver redraws it through a canvas to 32x32. Nothing is fetched, and a `favIconUrl` that is not a data: image stores nothing. The saver loads the stored keys into memory once, so an unchanged icon costs no read and no decode, also after a restart. A host is saved at most once per 3 minutes. One redraw per host runs at a time, and a failed redraw is not tried again until the icon changes. A save of an unchanged entry writes nothing, a full storage warns once, a private tab saves nothing, and a save that began before "Clear all history" is dropped (`background/history_clear.ts`). Writes queue so two saves that finish together both land. There is no other forget path to wire it into.
- `clock.ts`: the 12 hour SVG clock without ticks. Hand angles keep growing past 360 so the CSS transition never rewinds at a wrap.
- `digital_clock.ts`: the digital clock, `HH:mm` in seven-segment digits, with an AM or PM suffix when `newtab_clock_format` is 12 (the default). `fonts/` holds the font, DSEG7 Classic by keshikan, unmodified with its SIL OFL 1.1 text. The licence reserves the name "DSEG", so do not convert or edit the file. Only `newtab.html` declares it.
- `newtab.html`: the page and its styles, and the built-in links (Getting Started, Help, Settings) as plain anchors in a fixed `nav`, so hints reach them. Every bundle except `content.js` loads on first use, as on a website. `executeScript` cannot reach extension pages, so the background asks `main.ts` to add the tag (`shared/page_bundle_tag.ts`), and a new bundle needs no edit here.

Firefox gives the address bar focus on Ctrl+T. Press Esc or click the page before the keys work.

After Firefox's one-time "Your new tab has changed" notice, its hidden Keep Changes button keeps access key K for that browser session. So Alt+K (previous tab) does nothing on about: pages until a restart. Accepting the notice once avoids it.

`newtab.html` links `page_base.css` (`src/shared`) first, the same base as the help page, so both pages share one palette, type scale and key cap and card styles. Its rules read `var(--desertfox-*)` with no fallback and declare no color, so the theme sheet and `style.css` win. The page sets the extension icon as its tab favicon.
