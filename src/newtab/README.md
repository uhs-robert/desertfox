# newtab

The new tab page. The manifest sets `chrome_url_overrides.newtab` to `newtab.html`, so the page owns every new tab.

- `main.ts`: reads the `new_tab_page` setting through `resolve_new_tab_page` (`shared/config.ts`). A web URL redirects with `location.replace`, so the content script runs on that site as on any page. Anything else draws the built-in page, and so does `newtab.html?builtin`, which `home_page = "desertfox"` opens.
- `render.ts`: draws the built-in page: the clock, the date and the lists, each on unless its setting is `false`. `main.ts` draws through `follow_settings` (`shared/storage_watch.ts`), so a settings change redraws the page: the new page is built off screen and swaps in, the old clock stops first (`run_ticker` returns its stop), and only the first draw may redirect for `new_tab_page`. `newtab_clock` is analog for `true` or `"analog"` and digital for `"digital"`. A 1 second tick moves the hands and rewrites the date, so a tab left open past midnight shows the new day.
- `lists.ts`: the rows under the clock: `[[newtab_links]]` by group, then Recent tabs and Bookmarks, each hidden unless `newtab_recent_tabs` or `newtab_bookmarks` is true (`newtab_*_max` rows, default 8). It runs the tab and bookmark readers of the completion (`background/complete_items.ts`) on the page, with no background message, so it filters on its own: private tabs never show, and a private page lists no tabs. Recent tabs sort by `lastAccessed`, bookmarks by date added. A recent tab row switches to its tab. A reader that fails drops its list. Each row carries its host (without `www.`) and an `icon_url` from local sources only, in this order: the tab's own `favIconUrl` (http, https or a small data: URL), then the favicon cache for the host, then none, which draws a letter tile.
- `tile.ts`: one card per row, icon box, title and host, with the whole card as the one anchor, so a hint labels it once. The icon is an `img` that swaps to the letter tile when it fails to load. The letter tile is a `color-mix` of `--desertfox-primary` and `--desertfox-bg-mantle`, so it follows the theme. The grid in `newtab.html` is two 14rem columns, one on a narrow window, and fills row by row, so DOM order is visual order.
- `icon_cache.ts`: the favicon cache, `favicon_cache` in `storage.local`: host to a data: image URL, at most 200 hosts (the oldest drops first, a host that loads again moves to the newest end) and at most 2048 characters per icon. It stores data: icons only, because a stored https address would make a card fetch it: no icon service and no network request. The background writes it from the shared `tabs.onUpdated` listener in `background/main.ts` when a load completes or the icon changes, and a private tab stores nothing. Writes queue so two tabs that finish together both land. "Clear all history" in Firefox clears it (`background/history_clear.ts`). There is no other forget path to wire it into.
- `clock.ts`: the 12 hour SVG clock without ticks. Hand angles keep growing past 360 so the CSS transition never rewinds at a wrap.
- `digital_clock.ts`: the digital clock, `HH:mm` in seven-segment digits, with an AM or PM suffix when `newtab_clock_format` is 12 (the default). `fonts/` holds the font, DSEG7 Classic by keshikan, unmodified with its SIL OFL 1.1 text. The licence reserves the name "DSEG", so do not convert or edit the file. Only `newtab.html` declares it.
- `newtab.html`: the page and its styles, and the built-in links (Getting Started, Help, Settings) as plain anchors in a fixed `nav`, so hints reach them. Every bundle except `content.js` loads on first use, as on a website. `executeScript` cannot reach extension pages, so the background asks `main.ts` to add the tag (`shared/page_bundle_tag.ts`), and a new bundle needs no edit here.

Firefox gives the address bar focus on Ctrl+T. Press Esc or click the page before the keys work.

After Firefox's one-time "Your new tab has changed" notice, its hidden Keep Changes button keeps access key K for that browser session. So Alt+K (previous tab) does nothing on about: pages until a restart. Accepting the notice once avoids it.

`newtab.html` links `page_base.css` (`src/shared`) first, the same base as the help page, so both pages share one palette, type scale and key cap and card styles. Its rules read `var(--desertfox-*)` with no fallback and declare no color, so the theme sheet and `style.css` win. The page sets the extension icon as its tab favicon.
