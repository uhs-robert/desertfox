# editor

The `editor` bundle (`editor.js`, 4 KB limit). The background injects it into a frame on the first `text.edit_external` (`<C-i>` in insert mode).

- `main.ts`: the handler reads the focused field and refuses a non-editable focus, an editor that shows only part of its text (CodeMirror, Ace, Monaco and the hidden textarea of CodeMirror 5, by container class), a password field (`is_secret_field`) and text over the host's 128 KiB cap, then sends `editor_open` to the background with a fresh token. The background answers with a refusal (a second editor in the tab, a host error), which the key shows as a toast. The edit stays in a page-local map by token, with the field and its text at the press. When `editor_done` arrives, the page answers `true` for a token it knows, so the background can send the text to the register when it does not. An unchanged field takes the result: a plain input or textarea through the native value setter and `input` and `change` events, a contenteditable through `type_at_caret` over its whole content (`delete` for an empty result). The check runs again after `focus()`. A field that changed, left the page or refused the write keeps its text, and the result goes to the unnamed register. The toast says which of the cases it was, and claims the register only once the register took the text.
