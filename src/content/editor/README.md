# editor

The `editor` bundle (`editor.js`, 6.5 KB limit). The background injects it into a frame on the first `text.edit_external` (`<C-o>` in insert mode).

- `main.ts`: the handler reads the focused field and refuses a non-editable focus, a password field (`is_secret_field`) and text over the host's 128 KiB cap, then sends `editor_open` to the background with a fresh token. The background answers with a refusal (a second editor in the tab, a host error), which the key shows as a toast. The edit stays in a page-local map by token, with the field and its text at the press. When `editor_done` arrives, the page answers `true` for a token it knows, so the background can send the text to the register when it does not. An unchanged field takes the result: a plain input or textarea through the native value setter and `input` and `change` events, a contenteditable through `type_at_caret` over its whole content (`delete` for an empty result). The check runs again after `focus()`. A field that changed, left the page or refused the write keeps its text, and the result goes to the unnamed register. The toast says which of the cases it was, and claims the register only once the register took the text.
- `clipboard_fallback.ts`: the path for editors that show only part of their text (CodeMirror, Ace, Monaco and the hidden textarea of CodeMirror 5, found by container class). It saves the clipboard text, writes a marker, focuses the editor's content element, sends a synthetic Ctrl+A (Cmd+A on macOS) and runs `execCommand("copy")` through `exec_clipboard_command` of `site_actions/clipboard.ts`. An uncancelled Ctrl+A, a copy event nobody saw, the marker still on the clipboard or a copy that misses one of the drawn lines (a keymap that binds Ctrl+A to another command), compared without whitespace, keeps the refusal. The saved text goes back before the editor opens, so a navigation strands nothing. Every copy that no write follows ends with an ArrowLeft, so no select-all waits for the next typed key. On return it checks the element is still on the page, copies again and compares with the opened text, writes the result to the clipboard, checks the drawn lines again, then selects all and pastes (`cut` for an empty result). A last copy reads the document back and compares it exactly, because a read-only editor sees the paste and drops it. It skips the drawn-lines check, as Ace and Monaco redraw a frame later. A failure at any step sends the result to the unnamed register. A clipboard that could not be restored refuses the open, and after a return the toast says so. Presses and returns in one frame run one at a time through `queued_in_page`. Only text is saved, so an image or HTML on the clipboard is lost, and a toast says the clipboard was used. The whole document passes through the system clipboard, where a clipboard history tool can record it.
