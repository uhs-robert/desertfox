# page

The `page` bundle (`page.js`, 5 KB limit). The background injects it into a frame on the first run of `scroll.align`, `copy.url`, `page.focus_input`, `mark.add`, `mark.jump` or `page.jump`. These commands are rare, so their code stays out of `content.js`. The bundle also answers the background's `get_selection` and `get_jump_offset` messages (the router asks for the offset before a command with the `jumps` flag, which loads this bundle on the first such command in a page), reports the offset as the page hides (`jump_leave`), and the background injects it when a frame gives no answer (`background/selection_ask.ts`).

- `selection.ts`: the selected text of the frame, read from the focused text field first and from the page selection otherwise.
- `main.ts`: registers the six handlers with the host and the `get_selection` listener. `mark.add`, `mark.jump` and `page.jump` (a step of the jump list) read the scroll box through the host (`scroll_box_`, which ends a smooth scroll in flight, because that state lives in `content.js`) and talk to the background mark store, and a jump scrolls with `behavior: "instant"`, unless the answer carries no offset: then the background moves to the tab of a global mark and the arrival jump scrolls. `page.focus_input` also marks the field it focused as the entry of typed text (`../text/entry.ts`). The code of the other three sits in `../handlers/align.ts`, `copy.ts` and `focus_input.ts`. The mark code sits in `main.ts`. The last blurred field and the toast come from the host (`last_blurred_`, `show_toast_`), because this bundle has no copy of the content script's state.
