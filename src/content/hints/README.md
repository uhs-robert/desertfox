# hints

The `hints` bundle (`hints.js`). The background injects it into a frame on the first `hint.run` or the first entry into `hint` mode.

- `main.ts`: registers the `hint` sink and the `hint.run` handler. `hint.run` enters hint mode at once, finds the visible elements, draws labels and waits for one to be typed. Keys typed while it finds elements wait and replay. Reads the `hint_letters` setting from the stored config status. With `rapid`, a pick keeps hint mode and builds the hints again, so deleted or moved elements stay right, and Escape ends it. With `text`, only links whose text holds it (ignoring case) get labels. One match runs at once and ends hint mode, also with `rapid`. None shows "No link matches ...". A custom selector that does not parse shows a notice.
- `candidates.ts`: one query per filter (`buttons` takes `button`, `[role=button]` and the button-like `input` types, enabled only), a selector and an optional test for what a selector cannot say (`prose` keeps the elements with a non-blank text node of their own, so a wrapper of spans gets no hint; `scrollable` keeps the boxes `is_scroll_box` accepts, see `../scroll_box.ts`; `media` takes `video, audio` and `main.ts` skips the cover test for it; `images` keeps an `img`, an image button or a box with a CSS background image, from 24 px on both sides (`is_image`), and skips the cover test too; `frames` keeps `iframe` and `frame` from 24 px on both sides, never the command line frame (`is_pickable_frame`), and keeps the cover test), plus "weak" candidates for `all` and `clickable`: a pointer cursor where it starts (or on any `<a>` without href), and a `tabindex=-1` item with a click-like role or inside a menu or a roving group (a tabindex 0 sibling). A weak candidate gives way to a visible clickable element inside it or around it (checked after the visibility pass), so a page of pointer wrappers gets one hint per thing. A walk that reaches open and closed shadow roots and same-origin frames. The walk stops at a frame of another site: that frame hints itself once the user focuses it and its own script starts.
- `visible.ts`: keeps what a person can click: inside every scrolling box, not hidden, and not under another element. Tries up to eight points per link (the middle of each line box, then the corners of the first), so a wrapped link or one part covered still counts. The boxes are clipped to the scrolling ancestors first (not body, html, or inline boxes, and each axis on its own), so a half scrolled item is probed on its shown half. A box with no area (also `display: contents`, which an IntersectionObserver ignores) falls back to its children's boxes and observes them. `anchor_box` gives the label the same fallback, and a link with no box gets a hidden label. Tested in each parent document for a framed element. Reads the page only through `PageProbe`, so tests use a fake page.
- `labels.ts`, `pick.ts`: the label generator (prefix-free, built from the letters) and the typing rules. Pure.
- `actions.ts`: what a picked element gets: a click, a focus, open in a place, copy the address (`copy`, the text for an element with no address, a refusal for a picture with none; `element_address` reads the element's own href, image or media source, never an ancestor's) or the text (`copy_text`), the picture (`copy_image`) or a saved file (`download`), both of which send the address to the background and never fetch it here (a missing answer from the background is a refusal), focus, delete, hover, and on media play or pause, mute and fullscreen (`player_box` finds the element to show). A click is the whole mouse sequence (pointerover, pointerenter, mouseover, pointerdown, mousedown, focus, pointerup, mouseup, then `click()`), so dropdowns that open on mousedown open. A cancelled pointerdown skips the mousedown, mouseup and focus, and a cancelled mousedown skips the focus, as in a browser. A field only takes focus. `dispatch_mouse_event` sends one event and is the piece a hover action reuses. `focus` gives an element with no `tabindex` attribute `tabindex=-1` first (a page's own value stays) and, for anything but a field, flashes an outline for under a second, so `;s` shows which box a scroll key now moves. `hover` (`hover.ts`) moves a pointer like a real one: pointerout and mouseout on the old element (with `relatedTarget`), leave only on the old element and ancestors that do not contain the new one, then over, enter (only on ancestors the pointer was not in), pointermove and mousemove from the middle of the new one. So hovering an item inside a hovered menu keeps the menu entered. Ancestors include the shadow host above a shadow root, and one point (the new element's middle, or where the old one was entered) serves the whole move. A pick inside the hovered element makes the picked element the hovered one, so Escape still closes the menu. A new hover, Escape (the `hint.unhover` handler, called from `mode.escape`), a hidden tab or another pick (toward its target) ends the hover. A removed element gets no events. Synthetic events do not set CSS `:hover`. `caret` and `visual` hand the element to the caret bundle (see `caret/main.ts`, `start_session`) and ignore `rapid`.
- `view.ts`: labels in a closed shadow root. A label is filled with `--desertfox-primary`, with a 1px `--desertfox-primary` border so its size stays the same, and its text is `--desertfox-bg-core`. The letters already typed show at 60% opacity.
- `headings.ts`: the headings of the page for the `heading` command (`src/commands/heading.ts`), which the command line lists. `heading.list` reads the page and keeps a snapshot of the headings and their frames, `heading.go` jumps to one by its number or its text, and `heading.clear` drops the snapshot. The command line host calls the three (`src/cmdline/host.ts`). Headings are checked with `keep_present` and not `keep_visible`: a box of real size that no scroll box clips and that `checkVisibility` (visibility and opacity) accepts (Firefox gives the content of a closed `<details>` a box, so a box test alone keeps it), wherever it sits on the page. A heading in a frame passes only when its frames pass the same rules. `heading.go` refuses with "That heading is gone" when the element left the page, and scrolls the heading and then each frame that holds it to the top, innermost first, touching nothing else.
- `follow.ts`: repositions the labels on the next animation frame after a scroll or resize in the top window or a frame window.

The registry never imports this folder. The command and its params sit in `src/commands/hint.ts`.
