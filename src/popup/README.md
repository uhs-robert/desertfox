# popup

The toolbar popup (`default_popup`). It is a page of its own, so a click on the button never reaches `browserAction.onClicked`.

- `model.ts`: the rows, from plain inputs. No DOM, so tests read them. Row order: the on/off switch, Disable on this site, the rule row, Copy rule, Reload config, Settings, Help, Keys, the warnings count (only when it is above zero), Support DesertFox. The model also holds the rule text the Copy rule button copies (`rule_template`), the release link of the version (`release_url`: the tag for a release, the releases list for a beta), the theme list (`theme_options`), the host dot (`host_dot`) and the notice timer (`create_notice`: a success notice clears after 4 s, an error stays, and a newer notice cancels the older timer). Every state line and detail starts with a capital letter. `site_card` words the host and state line of the site card. The site row is grey while off, with "A rule covers it" when another row decides the page's `off` column, and with no site on a page that is not http or https. The rule row shows what the matching rows set ("All off", "Pass 3 keys", "Only 2 keys", "On, pass 1 key") and links to the Your site rules section heading of the settings page (`#section=settings/site-rules`, the id `settings-site-rules` that `src/help/render.ts` draws on that heading). Rule edits reach open tabs at once, so the popup offers no tab reload. Reload config is a button, not a link, and is grey without the native host.
- The site row saves a whole `site_rules` list that starts as the file's list, with an `off = true` row appended. Later file edits to `site_rules` do not apply until `:unset site_rules` clears it.
- `main.ts`: reads storage and the active tab when it opens, draws the header (icon, wordmark, version), the two-segment On/Off control (native radio buttons, so the arrow keys move the choice), the site card (host, state line, the site button and the rule line), the Reload config button with an inline icon, one split row for Settings and Help with inline SVG icons, the outlined Warnings row with a CSS chevron and the Support row with a heart icon, and sends the writes to the background (`toolbar_set_disabled`, `toolbar_site`, `toolbar_reload_config`). It writes nothing itself. The header carries the native host dot (it follows `desertfox_host_connected` in `storage.session` live) and the version as a link. The site card has a Copy rule button: it writes the clipboard, then opens the edit files section of Settings. Keys opens the Commands page. The theme dropdown sends `change_setting` with layer `temp`, so a pick lasts for this session only. A redraw restores focus by a `data-focus-key`, and only the newest draw may paint. Settings, Help and Warnings open the help page through `plan_help_tab`. Support DesertFox opens the GitHub Sponsors page in a new tab beside the active one, with no tracking. The popup themes like the help page and stays themed while off.
- `popup.html`: the page and its styles. The theme primary is the one accent, and every color has a hex fallback for the first paint.
